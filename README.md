# Rust Exercises

**Rust exercises. Human-written, human-debugged.**

A collection of exercises completed while learning the Rust programming language.

## Motivation

After years of professional software development, I decided it was time to take a step back and revisit programming fundamentals through Rust.
I saw this as an opportunity to challenge myself with a language that approaches several familiar concepts differently.
The goal was to learn the language properly: by writing code, solving problems, making mistakes, and understanding the underlying concepts.

## Approach

- All solutions are written manually.
- No AI-generated solutions.
- Exercises are completed incrementally, building on previously learned concepts.
